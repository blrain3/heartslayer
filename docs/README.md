# heartslayer-kit

An operations and verification toolkit for running and analyzing bottled_ai batches through the Corrupt Heart. The shell scripts coordinate guarded launches and monitoring; the Python tools inspect shop purchases and replay decisions using a separate bottled_ai checkout.

The toolkit does not include the game, mods, or bottled_ai itself. See the repository's [main README](../README.md) for prerequisites and usage.

Verify the shell and Python syntax with:

```bash
bash -n scripts/*.sh && python3 -m compileall scripts tools
```
